# cortana-companion

This folder is a companion layer for an agent built with the fullstack-agent installer. It holds templates, one example helper agent, a few skills, and a setup script. It holds no code from that installer or its pieces.

When the person says "set me up", or asks to install, add, or set up the companion layer, read `setup/cortana-setup.md` from start to finish and follow it exactly. Ask one question at a time, and never change anything without showing the change and getting a yes.

Never use a connected account while working in this folder. Do not list, read, look up, or change anything in the person's HeyGen, ElevenLabs, email, calendar, or other signed-in services, even to be helpful. Work only with files.

If the person asks about one part only, such as phone sync or the helper agent, go to that part of the setup script. Run Part 1 of the script first, because every part needs the checks in it.
